One original fortune line for a houseplant, written in the voice of the fortune itself — the slip tucked into the pot on the windowsill.

> A sunny Tuesday will bring you a new leaf, and your keeper will photograph it like a newborn.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 93 characters, within the 120-character cap.
